The recorded plain URDF is preserved byte-for-byte as `model.urdf`. Only the
mesh files referenced by that URDF are mirrored. Browser resolution maps the
`talos_data` ROS package name to this folder; model data is unchanged.

`talos-data` explicitly records plain URDFs for use without ROS/Xacro and
directs users to PAL Robotics for initial data validated by the manufacturer.
